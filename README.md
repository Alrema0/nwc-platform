# منصة الأعمال الموحدة — شركة المياه الوطنية

## محتوى المجلد

```
index.html            ← المنصة كاملة (الواجهة + الأقسام)
tasks/index.html      ← صفحة المهام وحدها
analysis/index.html   ← صفحة التحليل الشامل وحدها
```

## طريقة الرفع على GitHub

1. أنشئ مستودعاً جديداً في حسابك باسم `nwc-platform`.
2. ارفع محتوى هذا المجلد كما هو، مع المجلدين `tasks` و`analysis`.
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.

لا تغيّر شيئاً في مستودع `project-inventory`، فهو يبقى صفحة مستقلة كما هو.

## الروابط بعد النشر

| ترسل | الرابط |
|---|---|
| المنصة كاملة | `https://alrema0.github.io/nwc-platform/` |
| حصر المشاريع وحده | `https://alrema0.github.io/project-inventory/` |
| المهام وحدها | `https://alrema0.github.io/nwc-platform/tasks/` |
| التحليل وحده | `https://alrema0.github.io/nwc-platform/analysis/` |
| حصر الأصول (لاحقاً) | رابط صفحته بعد نشرها |

## إضافة صفحة حصر الأصول لاحقاً

1. انشر صفحة حصر الأصول في مستودع خاص بها، مثل `asset-inventory`.
2. في الملفات الثلاثة (`index.html` و`tasks/index.html` و`analysis/index.html`)، ابحث عن السطر التالي:
   `assets:''`
3. ضع رابط الصفحة بين علامتي التنصيص:
   `assets:'https://alrema0.github.io/asset-inventory/'`

## ملاحظات

- اسم النظام يتغيّر من السطر `const SYSTEM_NAME=` في الملفات الثلاثة.
- داخل المنصة كل الأقسام تفتح فيها، والرجوع بزر «الرئيسية». الصفحات المنفصلة للمشاركة فقط، وروابطها من زر «مشاركة» في كل قسم.
- صفحة المهام: يسجل الموظف ما أنجزه ويربطه بمستهدف الإدارة (المرتبط بمستهدف المنشأة). تُضبط الزيارات الدورية المطلوبة لكل موظف ومعيار سرعة الاستجابة من زر «الموظفون والزيارات المطلوبة»، والمستهدفات من زر «المستهدفات».
- بيانات المهام تُحفظ في متصفح كل مستخدم. الصفحة المنفصلة والمنصة تعرضان نفس البيانات على نفس المتصفح.
